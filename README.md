# Project Crow

**Project Crow** is an operating system project built on **Cosmos Gen 3**, focused on creating a modular, extensible, and customizable operating system with a supporting development framework.

At its core is **Crow OS**, the primary operating system developed as part of the project.

### Core Components
- **Crow OS** – The main operating system.
- **Crow DFI** – Crow Driver Framework Interface, providing standardized interfaces and infrastructure for driver development.
- **Crow EDK** – An extended development kit built on Cosmos Gen 3, providing additional abstractions, interfaces, and improvements.

### The Idea

Project Crow focuses on modularity, extensibility, and maintainability. Developed and maintained by a single developer (And Contributors), it aims to create a cohesive operating system with a clean and accessible development environment.
